STUDENT REGISTRATION FORM
=========================

1. PROJECT DESCRIPTION
----------------------

This project creates a simple Student Registration Form using:

- HTML
- Tailwind CSS CDN
- json-to-tag JavaScript CDN
- JavaScript
- JSON-based DOM structure


2. CDN USED IN THIS PROJECT
---------------------------

There are two CDN resources used.

A. Tailwind CSS CDN

<script src="https://cdn.tailwindcss.com"></script>

Purpose:
Tailwind CSS is used for styling the webpage.

Examples of Tailwind classes used:

These are Tailwind CSS utility classes.


B. json-to-tag CDN

import "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-tag@main/docs/dist/v4/min.js";

Purpose:
This JavaScript library converts the JSON specification into real HTML DOM elements.

It is NOT a CSS library.


3. IS THERE ANY EXTRA CSS?
--------------------------

There is no separate CSS file in this project.

There is also no:

<style>
</style>

block in the HTML.

All styling is done using Tailwind CSS classes inside the HTML/JSON structure.

Therefore:

- Separate CSS file: NO
- Internal CSS: NO
- Inline style attributes: NO
- Tailwind CSS: YES
- Tailwind CDN: YES


4. HTML STRUCTURE
-----------------

The main page contains:

- HTML document
- Head section
- Tailwind CSS CDN
- Body section
- Student Portal card
- Dynamic form container


5. MAIN FORM CONTAINER
----------------------

The following element is used as a container for the dynamically generated form:

<section id="student-form"></section>

JavaScript later finds this section and inserts the generated form into it.


6. JSON FORM STRUCTURE
----------------------

The form is created using a JavaScript object called:

const formSpec = { ... };


The JSON-like structure contains:

- Form
- Student Name field
- Mobile Number field
- Register button

9. SUBMIT BUTTON
----------------

Button text:

Register

Button type:

submit

The button is styled using Tailwind CSS classes.


10. JSON-TO-TAG FUNCTION
------------------------

The following code converts the form specification into a real HTML element:

const studentForm =
  window.ks.jsonToTag.buildSpecElement(formSpec);


The generated form is stored in:

studentForm


11. FORM SUBMISSION
-------------------

The form uses:

studentForm.onsubmit = (e) => {
  e.preventDefault();

  console.log("Name:",
    document.getElementById("name").value);

  console.log("Mobile:",
    document.getElementById("mobile").value);
};


e.preventDefault() prevents the browser from refreshing or submitting the form normally.

The entered Student Name and Mobile Number are printed in the browser console.


12. FINAL RENDERING
-------------------

The generated form is added to:

<section id="student-form"></section>

using:

document.querySelector("#student-form").append(studentForm);
