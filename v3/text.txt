Student Registration Form - Task Description

Task:
Create a Student Registration Form using HTML, Tailwind CSS, and json-to-tag.

Requirements:
1. Student Name input field
2. Mobile Number input field
3. Register button

Implementation:
- Created the student registration form using a JSON specification.
- Used the json-to-tag CDN to generate HTML elements from the JSON specification.
- Used Tailwind CSS for styling and responsive design.
- Added a gradient background and registration card design.
- Added icons for the Student Name and Mobile Number fields.
- Added a Register Now button with hover effects.
- Added form submission handling using JavaScript.
- Used preventDefault() to prevent the page from refreshing when the form is submitted.
- Displayed the entered Student Name and Mobile Number in the browser console.

Purpose of json-to-tag:
json-to-tag is used to generate HTML elements dynamically from a JSON specification instead of writing the HTML elements directly.
