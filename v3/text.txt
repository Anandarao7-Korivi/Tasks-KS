STUDENT REGISTRATION FORM
=========================

1. PROJECT OVERVIEW
-------------------

This project is a Student Registration Form created using:

- HTML
- Tailwind CSS CDN
- JavaScript
- json-to-tag CDN
- JSON-based DOM structure

The form contains:

- Student Name
- Mobile Number
- Register Now button
- Security information message


2. CDN USED
-----------

This project uses two CDN resources.


A. TAILWIND CSS CDN

<script src="https://cdn.tailwindcss.com"></script>

Purpose:

Tailwind CSS is used to design and style the complete webpage.

The project does not use a separate CSS file.

Examples of Tailwind CSS classes used:

B. JSON-TO-TAG CDN

import "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-tag@main/docs/dist/v4/min.js";

Purpose:

The json-to-tag library converts the JavaScript JSON specification into actual HTML DOM elements.

It is a JavaScript library.

It is NOT a CSS library.

- No separate style.css file

17. JSON-TO-TAG FUNCTION
------------------------

The following code converts the form specification into a real HTML form:

const studentForm =
  window.ks.jsonToTag.buildSpecElement(formSpec);


The generated form is stored inside:

studentForm


18. FORM SUBMISSION
-------------------

The form uses an onsubmit event:

studentForm.onsubmit = (e) => {
    e.preventDefault();

    console.log(
        "Student Name:",
        document.getElementById("name").value
    );

    console.log(
        "Mobile Number:",
        document.getElementById("mobile").value
    );
};


19. PREVENT DEFAULT
-------------------

The following code:

e.preventDefault();

prevents the browser from refreshing the page when the Register Now button is clicked.


20. GETTING STUDENT NAME
------------------------

The Student Name is obtained using:

document.getElementById("name").value

The value is printed in the browser console as:

Student Name:


21. GETTING MOBILE NUMBER
-------------------------

The Mobile Number is obtained using:

document.getElementById("mobile").value

The value is printed in the browser console as:

Mobile Number:


22. ADDING THE FORM TO THE PAGE
------------------------------

The generated form is added to the page using:

document.querySelector("#student-form").append(studentForm);


This finds:

<section id="student-form"></section>

and inserts the dynamically generated form inside it.

26. COMPLETE FLOW
-----------------

HTML Page
    ↓
Tailwind CSS CDN loads
    ↓
json-to-tag JavaScript CDN loads
    ↓
formSpec object is created
    ↓
buildSpecElement() creates the form
    ↓
Form is stored in studentForm
    ↓
Submit event is attached
    ↓
Form is inserted into #student-form
    ↓
User enters Student Name
    ↓
User enters Mobile Number
    ↓
User clicks Register Now
    ↓
Page refresh is prevented
    ↓
Student Name and Mobile Number
are printed in the Browser Console


27. IMPORTANT NOTE
------------------

Tailwind CSS is responsible only for styling.

json-to-tag is responsible for dynamically creating HTML elements from the JavaScript object.

JavaScript handles the form submission and reading the entered values.

No custom CSS is required in this project.
