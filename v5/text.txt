DYNAMIC STUDENT REGISTRATION FORM
=================================

1. PROJECT DESCRIPTION
----------------------

This project creates a dynamic Student Registration Form using:

- HTML
- Tailwind CSS CDN
- JavaScript
- json-to-tag CDN
- Array configuration
- JavaScript map() method
- Dynamic DOM generation

The form contains:

- Student Name
- Mobile Number
- City
- Register button

13. WHY fieldsConfig IS USED
----------------------------

Instead of manually writing every input field, all field information is stored in one array.

This makes the form easier to modify.

For example, to add an Email field, we can add another object:

{
  id: "email",
  label: "Email",
  type: "email",
  placeholder: "Enter email"
}

The JavaScript code will automatically create the field.


14. MAP() METHOD
----------------

The following code is used:

const dynamicChildren = fieldsConfig.map(field => ({
    ...
}));

The map() method goes through every object in fieldsConfig.

For each field, it creates:

- A div
- A label
- An input


15. DYNAMIC FIELD CREATION
--------------------------

For every field in fieldsConfig, JavaScript creates a structure similar to:

<div>
    <label>...</label>
    <input>
</div>

The label and input values come from the field configuration.


16. DYNAMIC LABEL
-----------------

The label is created using:

textContent: field.label

Therefore:

Student Name
Mobile Number
City

are automatically generated from the configuration.


17. DYNAMIC INPUT
-----------------

The input is created using:

id: field.id
type: field.type
placeholder: field.placeholder

Therefore the input properties are automatically taken from fieldsConfig.


18. REQUIRED INPUT
------------------

Every generated input contains:

required: true

This means the user must enter a value before submitting the form.


19. ADDING THE REGISTER BUTTON
-----------------------------

After generating the fields, the Register button is added using:

dynamicChildren.push({
    tagName: "button",
    ...
});


The button has:

type:
submit

text:
Register


20. FORM SPECIFICATION
----------------------

After creating all dynamic fields, the form specification is created:

const formSpec = {
    tagName: "form",
    attributes: {
        id: "studentForm",
        class: "space-y-4"
    },
    children: dynamicChildren
};


The important point is:

children: dynamicChildren

This means all dynamically generated fields and the Register button become children of the form.


21. JSON-TO-TAG FUNCTION
------------------------

The form is converted into a real HTML element using:

const studentForm =
  window.ks.jsonToTag.buildSpecElement(formSpec);


The json-to-tag library converts the form specification into an actual DOM element.


22. FORM SUBMISSION
-------------------

The form uses:

studentForm.onsubmit = (e) => {
    e.preventDefault();

    fieldsConfig.forEach(field => {
        console.log(
            `${field.label}:`,
            document.getElementById(field.id).value
        );
    });
};


23. PREVENT DEFAULT
-------------------

The code:

e.preventDefault();

prevents the browser from refreshing the page after clicking Register.


24. FOR EACH METHOD
-------------------

The following code is used:

fieldsConfig.forEach(field => {
    ...
});


The forEach() method goes through every field in fieldsConfig.

For each field, it gets the value from the corresponding input.


25. GETTING INPUT VALUES
------------------------

The input is found using:

document.getElementById(field.id).value


For example:

For Student Name:

document.getElementById("name").value


For Mobile Number:

document.getElementById("mobile").value


For City:

document.getElementById("city").value


26. CONSOLE OUTPUT
------------------

When the user submits the form, the values are printed in the browser console.

Example:

Student Name: Anand

Mobile Number: 9876543210

City: Guntur


27. ADDING FORM TO THE PAGE
---------------------------

The generated form is added using:

document.querySelector("#student-form").append(studentForm);


This inserts the dynamically generated form inside:

<section id="student-form"></section>

32. MAIN ADVANTAGE
------------------

The main advantage of this approach is that the form is dynamic.

Instead of manually creating every input field, the developer only needs to update fieldsConfig.

For example, adding:

{
  id: "email",
  label: "Email",
  type: "email",
  placeholder: "Enter email"
}

will automatically create an Email field.

Therefore, the same JavaScript logic can be reused for multiple form fields.


33. FINAL SUMMARY
-----------------

This project is a dynamic Student Registration Form.

Tailwind CSS CDN is used for styling.

json-to-tag CDN is used to convert the JavaScript form specification into DOM elements.

fieldsConfig stores the form field information.

map() dynamically creates the form fields.

push() adds the Register button.

forEach() reads the values during form submission.

No custom CSS is used in this project.
