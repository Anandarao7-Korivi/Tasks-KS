SIMPLE STUDENT REGISTRATION FORM
================================

1. PROJECT DESCRIPTION
----------------------

This project creates a simple Student Registration Form using:

- HTML
- Tailwind CSS CDN
- JavaScript
- json-to-tag CDN
- JSON-based DOM generation

The form contains:

- Student Name
- Mobile Number
- Register button


2. CDN USED
-----------

This project uses two CDN resources.

-------------------

The following CDN is used:

<script src="https://cdn.tailwindcss.com"></script>

B. JSON-TO-TAG CDN
------------------

The following JavaScript CDN is used:

import "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-tag@main/docs/dist/v4/min.js";

Purpose:

The json-to-tag library converts the JavaScript object specification into actual HTML DOM elements.

Important:

json-to-tag is a JavaScript library.

It is NOT a CSS library.


3. CUSTOM CSS

- No separate CSS file

8. DYNAMIC FORM CONTAINER
-------------------------

The following section is used as the form container:

<section id="student-form"></section>

The form is not directly written inside this section.

JavaScript dynamically creates the form and inserts it into this section.


9. FORM SPECIFICATION
---------------------

The complete form structure is stored in:

const formSpec = {
    ...
};

This JavaScript object describes the HTML form.

It contains:

- Form element
- Student Name field
- Mobile Number field
- Register button

14. JSON-TO-TAG FUNCTION
------------------------

The following code converts the form specification into an actual HTML element:

const studentForm =
  window.ks.jsonToTag.buildSpecElement(formSpec);


The generated form is stored in:

studentForm


15. FORM SUBMISSION
-------------------

The form uses:

studentForm.onsubmit = (e) => {
    e.preventDefault();

    console.log(
        "Name:",
        document.getElementById("name").value
    );

    console.log(
        "Mobile:",
        document.getElementById("mobile").value
    );
};


16. PREVENT DEFAULT
-------------------

The following code:

e.preventDefault();

prevents the browser from refreshing the page when the form is submitted.


17. GET STUDENT NAME
--------------------

The Student Name is read using:

document.getElementById("name").value

The value is printed in the browser console.


18. GET MOBILE NUMBER
---------------------

The Mobile Number is read using:

document.getElementById("mobile").value

The value is printed in the browser console.


19. ADDING FORM TO THE PAGE
--------------------------

The generated form is added to the page using:

document.querySelector("#student-form").append(studentForm);

This finds:

<section id="student-form"></section>

and inserts the generated form inside it.

24. FINAL SUMMARY
-----------------

This is a simple dynamic Student Registration Form.

Tailwind CSS is used only for styling.

json-to-tag is used to dynamically create the HTML form from a JavaScript object.

JavaScript handles form submission and reads the entered student information.

No custom CSS is used in this project.
